Objetivo do sistema

O sistema MINERTECH tem como objetivo realizar o cadastro e gerenciamento de funcionários, armazenando informações importantes e permitindo o acompanhamento dos registros. O Dashboard QA permite acompanhar os testes de qualidade e verificar o funcionamento das funcionalidades do sistema.

Dentro do escopo

  • Cadastro de funcionários
  • Validação de CPF
  • Validação de campos obrigatórios
  • Armazenamento dos dados
  • Visualização dos funcionários

Fora do escopo

  • Integração com bancos externos
  • Folha de pagamento bancária
  • Controle de ponto eletrônico
  • Integração com sistemas externos

Conclusão

Relatório de qualidade MINERTECH

O Dashboard permite acompanhar a execução dos testes, visualizar os resultados e identificar possíveis falhas no sistema. A integração com o cadastro de funcionários também facilita o acompanhamento dos registros e das informações de Recursos Humanos.

Os resultados apresentados dependem da execução real dos testes e dos funcionários cadastrados no sistema.
